# ☕ Coffee Machine OOP

A Python coffee machine simulation built using Object-Oriented Programming.

## Features

- Choose from espresso, latte, or cappuccino
- Checks available resources
- Processes coin payments
- Tracks profit
- Updates resources after making a drink

## OOP Concepts Used

- Classes and Objects
- Constructors
- Instance Attributes
- Instance Methods
- Importing and using multiple classes

## Project Structure

- `main.py` - Main program
- `menu.py` - Menu and drink classes
- `coffee_maker.py` - Coffee machine resource management
- `money_machine.py` - Payment processing

## How to Run

Run `main.py` using Python.
